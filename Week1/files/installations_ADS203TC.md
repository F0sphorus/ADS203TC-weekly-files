# Run Python in the computer lab for ads203tc

# First time installation



1\. open the anaconda prompt from the windows search bar

2\. execute the following commands

```
conda create -n ads203tc python=3.10

```

```
conda activate ads203tc

```

```
pip install numpy scipy matplotlib notebook ipywidgets

```



3\. in the same anaconda prompt, run the jupyter notebook

```
jupyter notebook

```

# After installation

1. reopen an anaconda prompt
2. activate the environment


```
conda activate ads203tc
jupyter notebook

```
